## 1. 为什么要筛选

Hough 检测的是几何线段，它并不知道哪些线段属于道路标线。沿用原项目的简单规则：排除过于接近水平方向的线段。

这只是针对当前道路画面的假设，不能证明保留下来的线段就是车道；真实场景中的道路形状、相机角度也可能使这个规则不合适。

## 2. 从端点计算方向

对端点 `(x1, y1)`、`(x2, y2)`，定义：

```text
dx = x2 - x1
dy = y2 - y1
```

当 dx 非零时，`abs(dy) / abs(dx)` 是斜率的绝对值。它越小，线段越接近水平。使用绝对值，可以同样对待向左上和向右上的线段；交换两个端点也不会改变筛选结果。

原项目丢弃满足下面条件的线段：

```cpp
std::abs(dy) < std::abs(dx) * 0.35
```

对于 dx 非零的情况，这与斜率绝对值小于 0.35 等价。0.35 是比例，不是 0.35 度，也不是图像宽高的比例。

代码采用乘法比较，避免除以 dx。当 dx 为 0、dy 非零时，线段是竖直的，上面的丢弃条件不成立，所以会保留。零长度线段没有方向，本课添加一条显式检查排除它。

例如：

- `(100, 200) -> (300, 220)`：dx = 200，dy = 20；20 < 70，丢弃。
- `(100, 300) -> (200, 200)`：dx = 100，dy = -100；100 < 35 不成立，保留。

## 3. 由你添加筛选代码

在头文件区域添加：

```cpp
#include <cmath>
```

在输出 `Line segments` 之后、`cv::Mat preview = image.clone();` 之前添加：

```cpp
const double min_abs_slope = 0.35;
std::vector<cv::Vec4i> kept_lines;

for (const auto& segment : lines) {
    const double dx = segment[2] - segment[0];
    const double dy = segment[3] - segment[1];

    if (dx == 0 && dy == 0) {
        continue;
    }
    if (std::abs(dy) < std::abs(dx) * min_abs_slope) {
        continue;
    }
    kept_lines.push_back(segment);
}

std::cout << "Kept line segments: " << kept_lines.size() << "\n";
```

这里出现的语法：

- `double`：浮点数类型，用于表示小数和参与比例计算。
- `std::abs`：求绝对值。
- `&&`：逻辑与，左右条件同时成立才为真。
- `continue`：跳过本次循环剩余语句，继续处理下一条线段；它不会退出整个函数。
- `push_back(segment)`：在容器末尾追加当前线段的一份副本。

坐标来自当前图片中的整数像素位置，dx、dy 转成 double 后零值可直接比较。

接着只把原有绘制循环的这一行：

```cpp
for (const auto& segment : lines) {
```

改成：

```cpp
for (const auto& segment : kept_lines) {
```

注意区分两个循环：前面的筛选循环仍遍历 `lines`；后面的打印端点、画线循环才遍历 `kept_lines`。绘制和图片保存的其他代码保持原样，输出仍为 `build/lines_preview.png`。
